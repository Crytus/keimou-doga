# keimou-doga（啓蒙動画作成スキル）

健康・科学・社会問題などをテーマにした**啓蒙動画**を、情報収集からシナリオ作成、シーン分割、画像生成プロンプト、動画ツール用ファイルの出力まで一貫して作成するためのエージェントスキルです。

## 概要

このスキルは次のワークフローをエージェントに実行させます。

1. **情報収集** — 複数の観点から Web 検索を行い、統計や公式情報など信頼できる事実を収集
2. **構成設計** — オープニング・5章構成・まとめ／エンディングの全 20〜30 シーンを設計
3. **シナリオ作成** — シーンごとにナレーション・画像生成プロンプト・BGM 案を Markdown で作成
4. **要約ファイル作成** — `abstract.md`（約400字）と `detail.md`（約2000字）
5. **シーン画像プロンプト CSV** — `*_scenes.csv`（`scene_num,scene_name,seed,file_name,positive_prompt`）
6. **動画ツール用 YAML** — テンプレート `templates/scenes.yaml` にシーンを挿入した `scenes.yaml`

### 章構成

| 区分 | 内容 | シーン数 |
| --- | --- | --- |
| オープニング | 感情に訴える比喩で興味を引く | 2〜3 |
| 第1章 | 現状・定義・統計 | 3〜5 |
| 第2章 | 仕組み・種類 | 4〜5 |
| 第3章 | 見分け方・警告サイン | 3〜5 |
| 第4章 | 行動・予防 | 3〜5 |
| 第5章 | 希望・未来 | 3〜4 |
| まとめ＋エンディング | 要点の振り返り | 2 |

エンディング（`E-1`）はテンプレートに固定で含まれており、生成されたシーンはその直前に挿入されます。

## ディレクトリ構成

```
keimou-doga/
├── SKILL.md              # スキル本体（手順・注意点）
├── templates/
│   └── scenes.yaml       # 動画ツール用 YAML テンプレート
├── README.md
└── LICENSE
```

## インストール

スキルを読み込むエージェントのスキルディレクトリ（例: `.agent/skills/` や `~/.claude/skills/`）にクローンしてください。

```bash
git clone https://github.com/Crytus/keimou-doga.git .agent/skills/keimou-doga
```

## 使い方

エージェントに次のように依頼すると、このスキルが利用されます。

```
「睡眠不足」をテーマに啓蒙動画を作成してください。
```

## 出力ファイル

| ファイル | 内容 |
| --- | --- |
| `<テーマ>.md` | シナリオ本体（末尾に参考文献） |
| `abstract.md` | 概要（約400字） |
| `detail.md` | 章ごとの詳細（約2000字） |
| `<prefix>_scenes.csv` | シーン画像生成プロンプト（UTF-8 BOM 付き） |
| `scenes.yaml` | 動画生成ツール用設定 |

## 主なルール

- ナレーションは「あなた」への語りかけ形式の自然な日本語
- 画像プロンプトは文字・ロゴ・固有名詞・特定作家／スタジオの画風指定を含めず、`photorealistic style` を基本とする
- CSV と YAML のシーン ID・順序・画像パスを完全に一致させる
- 生成した YAML はパーサーで構文検証する
